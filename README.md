# Sistema de Gestão das Olimpíadas (SGO)

## Histórias de Usuário

### US01 - Cadastrar Competição

Como administrador, quero cadastrar competições no sistema,para organizar os eventos olímpicos.

---

### US02 - Editar Competição

Como administrador, quero editar informações de uma competição, para manter os dados atualizados.

---

### US03 - Remover Competição

Como administrador, quero remover competições cadastradas, para excluir eventos cancelados ou incorretos.

---

### US04 - Inscrever Atleta

Como administrador, quero inscrever atletas em competições, para permitir sua participação nas provas.

---

### US05 - Consultar Inscrições

Como administrador, quero visualizar os atletas inscritos em cada competição, para acompanhar a organização das provas.

---

### US06 - Validar País do Atleta

Como sistema, quero validar o país representado pelo atleta em cada modalidade, para garantir que ele represente apenas um país por modalidade.

---

### US07 - Alocar Local

Como administrador, quero definir locais para as competições, para organizar onde cada prova será realizada.

---

### US08 - Validar Conflitos de Horário

Como sistema, quero impedir conflitos de horário em um mesmo local, para evitar duas competições simultâneas no mesmo espaço.

---

### US09 - Registrar Resultados

Como administrador, quero registrar os resultados das competições,
para definir os vencedores e medalhistas.

---

### US10 - Definir Medalhistas

Como sistema, quero registrar ouro, prata e bronze para os atletas vencedores, para compor o quadro de medalhas.

---

### US11 - Gerar Relatório de Medalhas

Como administrador, quero visualizar o quadro de medalhas por país, para acompanhar o desempenho das delegações.

---

### US12 - Consultar Resultados

Como atleta, quero visualizar os resultados das competições, para acompanhar meu desempenho.

---

### US13 - Consultar Calendário de Competições

Como atleta, quero visualizar as competições cadastradas, para acompanhar datas, horários e locais das provas.
